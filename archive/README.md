# Archive

Preserved reference material, excluded from builds and Zig package distribution.

- `notes/cleanup-transcript.md`: the former root-level `trans` conversation export.
- `experiments/preview_proc_cat.zig`: an incomplete procedural-cat preview whose
  `proc_cat.zig` renderer is absent. Its historical imports are not active paths.
- `experiments/encode-cat-preview.swift`: an old contact-sheet/GIF encoder requiring
  raw frame dumps from a missing sprite-preview generator. It retains its original
  local paths as historical reference and is not a supported command.

These files were relocated rather than deleted. Use `zig build preview-cat` for
current renderer previews.
